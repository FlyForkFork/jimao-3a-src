# 几猫 3A 大作

> 单文件 WebGL 港口突袭 FPS：切断三处上行中继，穿过机械飞鸥与机械猎犬的封锁，登船撤离。

一个可以直接用浏览器打开的第一人称射击游戏 Demo。全部内容——Three.js 运行时、程序化材质、港区关卡、角色骨骼、敌人 AI、音频合成、HUD 与菜单——都打包在同一个 `index.html` 里，不依赖任何外部资源。

## 运行

直接用浏览器打开 `index.html`。或者起一个本地静态服务：

```bash
python -m http.server 8080
# 打开 http://localhost:8080/
```

需要支持 WebGL2 的桌面浏览器（Chrome / Edge / Firefox / Safari 新版）。首次启动会现场生成贴图与几何体，低配设备可以在设置里把画质调到「低」。

也支持触屏：左手拇指移动，右手拇指转视角，屏幕按钮负责开火、瞄准、换弹与跳跃。

## 玩法

- 港区里有三处上行中继，逐一靠近并按住 `E` 切断。
- 空中是机械飞鸥（会发射弹丸），地面是机械猎犬（会冲刺近战）。
- 每切断一处中继会触发一波增援；三处全断后撤离艇开放，跑到码头南端登船。
- 死亡后可在检查点重试；结算按用时、命中率、击杀数和重试次数评级。

## 技术栈

- **单文件交付**：`index.html` ≈ 1.4 MB，内嵌 Three.js r185 与全部游戏代码。
- **WebGL2 渲染**：自定义后处理链（AgX/ACES 色调映射、Bloom、镜头光晕、FXAA、胶片颗粒）、阴影、反射探针、程序化天空。
- **程序化内容**：集装箱、起重机、仓库、码头、地面水洼与锈迹全部由代码生成，无外部贴图/模型。
- **游戏系统**：胶囊体物理与射线检测、导航网格、飞鸥/猎犬两套状态机 AI、武器后坐力与弹道、WebAudio 合成音效与动态配乐。
- **UI**：原生 DOM/CSS HUD、罗盘、任务标记、字幕与设置面板，支持键鼠/触屏/手柄。
